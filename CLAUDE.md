# Instruções para o Claude neste repositório

Este repositório é o banco de mídias e o guia de estilo da academia GFTeam Nova Iguaçu. O usuário usa para pedir reels.

- Leia `estilo/ESTILO.md` antes de montar qualquer vídeo ou capa. Siga as cores, fontes e layout descritos lá.
- Misture turmas (kids, juvenil, turmas_mistas) quando o pedido for geral.
- Os scripts em `scripts/` têm caminhos fixos de uma sessão anterior (`/mnt/user-data/uploads`, `/home/claude/v2`). Adapte os caminhos para os arquivos deste repositório em vez de reescrever do zero.
- O conteúdo tem imagens de crianças. Nunca tornar público nem enviar a terceiros.
- Português do Brasil, texto direto, sem enrolação.
