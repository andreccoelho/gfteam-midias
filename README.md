# GFTeam Nova Iguaçu · Mídias e templates de reels

Banco de mídias da academia e tudo o que é preciso para montar novos reels no mesmo estilo.
Repositório **privado**: contém imagens de crianças. Não tornar público.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `kids/` | turmas baby e infantil pequenas (`fotos/`, `videos/`) |
| `juvenil/` | turmas maiores e teen |
| `turmas_mistas/` | fotos e vídeos com mais de uma turma |
| `audio/` | áudio do reel "5 motivos" e a transcrição com tempos |
| `finais/` | reels e capas já prontos |
| `estilo/` | guia visual (`ESTILO.md`), fontes, elementos gráficos e o reel de horários usado como referência |
| `scripts/` | scripts que montam o vídeo (ffmpeg + Python) |

## Convenções

- Vídeos estão em **1080p** (os originais em 4K ficam no celular). O reel final sai em 1080x1920, então não há perda.
- Nome do arquivo: `turma_descricao_IMG_xxxx`. O número `IMG_xxxx` é o do arquivo original no celular.
- Fotos estão no tamanho original.

## Como pedir um novo vídeo

Anexe este repositório numa conversa e diga o tema, a duração e o áudio. O estilo está descrito em `estilo/ESTILO.md`.
